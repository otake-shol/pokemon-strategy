# ポケモンチャンピオンズ戦略ページ

[公開ページ](https://otake-shol.github.io/pokemon-strategy/)

シングル・ダブルの構築、技・持ち物・能力ポイント、選出方針、採用理由、実戦での確認事項を掲載する非公式の個人用戦略ページ。

## 情報の基準日

現在のダブルページは2026年10月9日採用のフラエッテ・ニンフィア・ガオガエン・キラフロル・イダイトウ♂・アーマーガア。フェアリー2体を主軸に、アーマーガアのおいかぜとスカーフキラフロルの岩打点で補完する試運転構築。6体の技・持ち物・能力ポイント・実数値と相手別選出を掲載する。シングルタブは9月13日版を保持し、9月25日のダブル・9月13日のシングルは[履歴ページ](https://otake-shol.github.io/pokemon-strategy/history.html)にも残す。ゲーム内反映と新構成の実戦結果は未確認。

## 更新手順

非公開の記録用リポジトリで構築記録を編集し、`python3 scripts/build_site.py`でページを再生成する。生成した`index.html`・`history.html`・`.nojekyll`をこのリポジトリにコピーし、コミット・プッシュする。

GitHub Pagesは`main`ブランチのルートを公開する。会話ログ、個別対戦記録、認証情報を含めない。
