## 更新手順

非公開の記録用リポジトリで構築記録を編集し、`python3 scripts/build_site.py`でページを再生成する。生成した`index.html`・`history.html`・`.nojekyll`をこのリポジトリにコピーし、コミット・プッシュする。

GitHub Pagesは`main`ブランチのルートを公開する。会話ログ、個別対戦記録、認証情報を含めない。
