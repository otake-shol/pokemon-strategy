# ポケモンチャンピオンズ戦略ページ

[公開ページ](https://otake-shol.github.io/pokemon-strategy/)

シングル・ダブルの構築、技・持ち物・能力ポイント、選出方針、採用理由、実戦での確認事項を掲載する非公式の個人用戦略ページ。

## 情報の基準日

現在のダブルページは2026年10月9日採用のフラエッテ・エルフーン・ガオガエン・キラフロル・イダイトウ♂・ガブリアス。リキキリンを物理火力と電気無効のガブリアスへ変更し、ようき・さめはだ・いのちのたま・H2/A32/S32を採用。4技はじしん・ドラゴンクロー・いわなだれ・ほのおのキバ。じしんの味方への巻き込みと、雨・ブリジュラス対面の選出方針も掲載する。シングルタブは9月13日版、[履歴ページ](https://otake-shol.github.io/pokemon-strategy/history.html)は9月25日ダブルと9月13日シングルを保持する。2026年10月10日に実際の技構成を反映。エルフーンはムーンフォース・おいかぜ・がむしゃら・アンコール、ガオガエンはじごくづきをまもる、キラフロルはまもるをニードルガードへ変更。トリックルーム対策は始動妨害と時間稼ぎ、条件付きのアンコールによる解除。新構成の勝率は未検証。

## 更新手順

シングル・ダブルとも6体の設定と実数値を縦1列で一覧表示する。「ゆったり表示」で文字を拡大し、ポケモン名から詳細を開ける。選出候補を画像付きで表示し、対戦メモを形式別にブラウザ内へ保存する。2026年10月9日の表示更新で構成・技・持ち物・配分の変更はない。

非公開の記録用リポジトリで構築記録を編集し、`python3 scripts/build_site.py`でページを再生成する。生成した`index.html`・`history.html`・`.nojekyll`をこのリポジトリにコピーし、コミット・プッシュする。

GitHub Pagesは`main`ブランチのルートを公開する。会話ログ、個別対戦記録、認証情報を含めない。
