最終決定と変更履歴

メガフラエッテ

  • 当初のめいそう型から、めいそうをサイコキネシスへ変更。
  • ムーンフォースとまもるは両方とも維持。
  • 積まずに攻撃する方針に合わせ、H32・C2・S32からH2・C32・S32へ変更。ユーザーが採用を明言済み。
  • 変更によりHP181→151、特攻177→207。現在はめいそうで勝つ構築として説明しない。
  • サイコキネシスはオオニューラのエスパー4倍弱点を突く目的。フェアリー技は同相手に等倍。
  • 打点があっても安全に対面できるとは限らない。最速オオニューラはS189、かるわざ後はS378。後者はおいかぜ中のフラエッテより速い。相手のタスキにも注意。

エルフーン

  • フェアリーオーラを味方にも活かしたいというユーザー希望を受け、プテラから変更。
  • ムーンフォースで追加の特殊打点を持ち、おいかぜでフラエッテを支える。
  • がむしゃらの採用時、ユーザーがアンコールの維持を希望。最終的にまもるをがむしゃらへ変更。
  • 現在はまもるを持たない。ねこだまし・集中攻撃に注意して先発を選ぶ。
  • がむしゃらは攻撃技なのでいたずらごころで先制しない。ゴーストには無効。タスキで耐えても相手のもう1体の攻撃で倒される可能性がある。
  • エルフーンのがむしゃらからフラエッテのマジカルシャインで倒す連携が候補。通常の味方同士の行動順はS184→169。

ガオガエン

  • 通常ウインディ・オオニューラへの変更も比較したが、最終構成はガオガエンを維持。
  • いかく・ねこだまし・炎打点・すてゼリフを1体で担える点を評価。ゴリランダーを選出しない試合でもねこだましを確保できる。
  • ウインディはフェアリー半減、おにび・バークアウトが利点。ねこだまし・すてゼリフを失うため、代役として成立しても同じ運用にはならない。
  • オオニューラは高速の攻撃とねこだましが利点。いかくと炎打点を失う。ガオガエンとの比較は主にフラエッテのめいそう型を検討していた段階で実施し、その後の最終確認でもガオガエンを維持した。

特性と連携の要点

  • フェアリーオーラはメガフラエッテが場にいる間、敵味方のフェアリー技を約1.33倍にする。味方のエルフーンにも有効。相手のフェアリー技も強化される。
  • グラスフィールドは地面にいるポケモンをターン終了時に最大HPの1/16回復する。見た目で浮いていてもフラエッテは通常、地面にいる扱い。まもる中も回復し、相手も条件を満たせば回復する。
  • グラスフィールドでエルフーンのHPが回復すると、がむしゃらで相手を削れる先も回復後のHPになる。
  • ゴリランダーはサイコフィールドを上書きできる。ただし、リキキリンのテイルアーマーによる先制技封じはフィールド変更で解除できない。
  • ねこだましはゴースト・まもる・先制技を防ぐ効果などで通らない場合がある。
  • すてゼリフの交代先が安全に出られるかは行動順にも依存する。
  • ドドゲザンのまけんきで相手のいかくを牽制する。ヨプのみでも格闘技を必ず耐えるとは限らない。

基本選出と勝ち筋

基本選出は先発エルフーン＋フラエッテ、後発ガオガエン＋イダイトウ。おいかぜからフラエッテで削り、イダイトウで詰める。

  • 相手の水が強ければゴリランダーを検討。
  • 相手のフェアリーやいかくが気になる場合はドドゲザンを検討。
  • 先発にねこだましの妨害が予想される場合はガオガエン＋フラエッテなども検討。
  • フェアリー技が通りにくい鋼・毒に対して2体を並べ続けず、ガオガエンなどにつなぐ。

実戦での確認項目

確定は実戦に投入する構成の合意。勝率・到達ランク・上位帯での安定性は未検証。

  1. トリックルーム相手への選出とターンのしのぎ方。先制技もサイコフィールドやテイルアーマーに止められる場合がある。
  2. まもるを外したエルフーンがおいかぜ・アンコール・がむしゃらを使う機会を確保できるか。
  3. CS配分のフラエッテが十分に攻撃できるか。HPを削った影響とサイコキネシスの有用性。
  4. ねこだまし・すてゼリフが勝ちに貢献しているか。ウインディのフェアリー耐性やおにびを必要とする試合が多いか。
  5. プテラを外して失ったワイドガード・岩・飛行打点の影響。
  6. 相手のいかく、鋼・毒、範囲攻撃への対応。まけんきの存在だけで物理アタッカー全員を保護できるわけではない。

次回は相手の6体、自分の選出4体、勝敗、苦戦した行動やターンを確認して調整する。

配分はチャンピオンズの能力ポイントで各個体合計66。従来作品の努力値表記とは異なる。H＝HP、A＝攻撃、B＝防御、C＝特攻、D＝特防、S＝素早さ。

決定事項と採用理由

  • メガルカリオZの枠をサーフゴーへ変更。メガギャラドスと同時選出しても両方の性能を活かせることを重視。メガ枠はギャラドス1体とし、毎試合の選出・メガシンカは必須としない。
  • ストリンダーへの変更は見送り、ヒートロトムを継続。
  • サーフゴーのふうせんは地面技を一時的に無効化し、わるだくみ・じこさいせいの機会を作る目的。攻撃で割れた後も地面を無効化できるわけではない。CS配分なので万能な受け役にはしない。
  • アシレーヌはオボンのみ、ガブリアスはゴツゴツメットを採用。
  • ギャラドスはかみくだくをちょうはつへ変更済み。あくび・回復・積み技・吹き飛ばしなどへの対策を重視。じしんはメガ後のかたやぶりでロトムのふゆうを無視できる点も評価。
  • ガブリアスはどくづきを見送り、がんせきふうじを継続。HB配分の役割に合う素早さ操作を重視。地面等倍のフェアリーには一致じしんと抜群どくづきの威力差が小さい。
  • マスカーニャはユーザー希望でたつじんのおび。特性はしんりょく。きあいのタスキやへんげんじざいへ変更していない。
  • マスカーニャのはたきおとす枠はとんぼがえり・けたぐり等も比較したうえでかわらわりに確定。格闘打点と壁の破壊を兼任。
  • けたぐりはドドゲザンに威力100、ブリジュラスに80。かわらわりは固定75で、リフレクター・ひかりのかべ・オーロラベールを破壊。ブリジュラスへの威力差は小さいが、ドドゲザンへの火力はけたぐりが高い。
  • ギャラドスのかみくだくとマスカーニャのはたきおとすは両方とも不採用。悪技はふいうちだけなので、変化技を使う相手への安定した悪打点はない。ゴースト打点はサーフゴーのシャドーボールで確保。

構築査定

相談時の机上評価ではマスターボール級で十分戦える構成。現時点で必須の変更はなく、固定して選出と立ち回りを検証する方針。実戦勝率や上位帯での安定性は未検証で、到達や勝率を保証する評価ではない。

強みと勝ち筋

  • ガブリアスのステロ・さめはだ・ゴツメで削り、ギャラドスのりゅうのまいから全抜きを狙える。
  • サーフゴーのわるだくみ・じこさいせいで耐久寄りの相手を崩す別の勝ち筋がある。
  • ロトムのスカーフとマスカーニャの素早さ・ふいうちで終盤を詰められる。
  • 物理と特殊の攻め手がそろい、ちょうはつ・アンコール・トリック・ドラゴンテール・かわらわりで相手の展開にも干渉できる。

注意点

  1. 積んだ高速エースへの切り返し：最速メガボーマンダはりゅうのまい1回でS283となり、スカーフロトムのS226でも抜けない。タスキ持ちもいないため、氷技があるだけで安全とはいえない。自由に積ませず、ガブリアスのがんせきふうじ・ドラゴンテールやアシレーヌの氷打点を使う。ドラゴンテールも相手の攻撃を耐えられるか判断が必要。
  2. ロトムへの役割集中：鋼・草への対応、交代技、高速相手の処理を兼任。メガグソクムシャ・メガハッサム等がいる試合では特にHPを残す。高速相手が残っている状況でのスカーフトリックは慎重に判断。
  3. ステルスロックによる消耗：ロトムとメガ前のギャラドスは登場時に最大HPの約1/4を失う。除去技がなく、回復技持ちもサーフゴーだけなので長い交代戦は苦手。
  4. ギャラドスの攻撃範囲：水・地面の2技ではボーマンダや草タイプなどに通しにくい。ちょうはつで回復を止めても必ず突破できるわけではない。選出段階でサーフゴーやアシレーヌを勝ち筋にする判断も必要。
  5. マスカーニャの行動機会：帯は抜群火力を補うが、タスキのように一撃を耐える保証はない。ふいうちは相手の変化技や交代には通らず、アクセルにも命中の不安がある。

ギャラドスの運用

  • 序盤のいかくと終盤のりゅうのまいを使い分ける。AS配分・回復なしなので繰り返し受け続ける役にはしない。
  • メガ前は地面無効・格闘半減。メガ後はエスパー無効・ゴースト半減になる一方、草・格闘・虫・フェアリーが弱点になる。電気は4倍から2倍へ変わる。
  • 交代で出す瞬間にはメガシンカできないため、メガ前の状態でエスパー技へ無効受けはできない。
  • かたやぶりのじしんはふゆうを無視するが、ひこうタイプの地面無効は無視しない。
  • ちょうはつは既に受けたあくびを解除しない。また、ボディプレスやイカサマなどの攻撃技は止められない。
  • 最速ギャラドスはS146、りゅうのまい1回でS219。最速メガルカリオZのS223には届かない。

選出の出発点

固定の正解ではなく、相手の6体と勝ち筋に合わせて調整する。記載順は必ずしも先発順を意味しない。

実戦での確認項目

まず20〜30戦ほど固定して試すことを提案済み。これは見直しのための目安で、勝率を統計的に確定する試合数ではない。

  • 相手の主要ポケモンと自分の選出3体。
  • 勝敗と、勝負が決まったターンの行動。
  • 積まれて止まらなかったか。
  • ロトムが先に消耗したか、スカーフを手放すのが早かったか。
  • ギャラドスの攻撃範囲が足りなかったか。
  • かわらわりの壁破壊が役立ったか、格闘打点として火力不足だったか。
  • 技を変更すべき問題か、選出やHPの温存で改善できる問題か。

2026年9月13日のユーザー報告：サーフゴーはそもそも選出しないことが多い。マスカーニャ・アシレーヌ・ギャラドスの3体を選出することが多く、ガブリアスとヒートロトムもたまに選出する。

追加のユーザー報告：アーマーガアが少しきつい。相手の技構成・試合数・勝敗は未確認。現時点では構成変更なし。

次の検討案：アーマーガア入りにサーフゴーまたはヒートロトムを選出して対応する。ボディプレス主体のアーマーガアに対するサーフゴーの役割を実戦で確認してから、6枠目の変更を判断する。選出案は未検証。
